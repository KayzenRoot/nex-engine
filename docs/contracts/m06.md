# NEX M06 performance contract v1

**Status:** `CONTRACT_ONLY_NOT_MODULE_ADMISSION`. This document and the files under `contracts/m06/` define an interface and a prospective ownership map. They do **not** implement M06, run a capture, measure performance, or admit any M06 sub-increment.

## Purpose

`performance.v1.schema.json` describes one bounded performance observation: workload identity, frame intervals, GPU/CPU/pacing timings, renderer resources, a bottleneck classification with evidence and confidence, an optional comparison against a baseline observation, and provenance.

## Invariants

1. **No fabricated measurements.** `MEASURED` requires a finite nonnegative value; `UNAVAILABLE` requires a reason and forbids a value.
2. **No FPS claim.** The contract carries frame intervals and millisecond timings, not FPS. A consumer must not derive an FPS claim from synthetic/headless data.
3. **Workload identity.** `scene_id`, `proxy_count`, `effect_mode`, positive resolution, vsync and `max_fps` are explicit so observations cannot be mixed silently.
4. **Bottleneck coherence.** A `gpu` classification with measured/derived evidence requires `gpu_render_ms` MEASURED; `cpu` requires `cpu_render_ms`; `pacing` requires `frame_pacing_ms`; `memory` requires `vram_used_bytes`.
5. **Unknown is honest.** `insufficient_data` requires every timing/resource metric to be UNAVAILABLE; evidence `unavailable` is only valid for `unknown` or `insufficient_data`.
6. **Comparison is optional.** When present, it names a baseline `observation_id` and carries delta GPU/CPU milliseconds in `[-10000, 10000]`; it does not imply statistical significance.
7. **Provenance.** `base_sha`/`head_sha` are lowercase 40-hex Git object IDs; evidence URI is required when `measurement_status` is `MEASURED`.
8. **Representation only.** Passing schema validation does not prove a bottleneck, a regression or a performance result.

## Validation

```powershell
python -m unittest discover -s tests/contracts -p 'test_*.py' -v
```

The tests use the repository's limited standard-library schema checker with local `$ref` expansion; unsupported keywords are avoided.

## Ownership

`ownership.v1.json` maps prospective M06 write paths (atlas, LOD, culling, streaming, frame pacer) to single writers. Paths under `nex_modules/performance/**` do not exist yet and no module is admitted. Contract consumers are read-only.

## Compatibility

A breaking change to a required field, enum, availability semantics or provenance meaning requires `performance.v2` and a new ownership revision. Additive optional fields are allowed only after the Steward updates this document and the tests.
