# NEX M10 combat feedback contract v1

**Status:** `CONTRACT_ONLY_NOT_MODULE_ADMISSION`. This document and the files under `contracts/m10/` define an interface and a prospective ownership map. They do **not** implement M10, animate anything, create a camera effect, measure game feel, or admit any M10 sub-increment.

## Purpose

`feedback.v1.schema.json` describes one bounded combat-feedback observation: attack phases, hit events, feedback channels (hit-stop, camera shake, flash, recoil, damage number), channel priority/intensity, feedback budgets, availability-gated performance and provenance.

## Invariants

1. **No fabricated measurements.** `MEASURED` requires a finite nonnegative value; `UNAVAILABLE` requires a reason and forbids a value.
2. **No FPS claim.** The contract carries frame intervals and millisecond timings, not FPS.
3. **Attack phases.** Phase names are unique, `active` is required, and the total attack duration is at most 10000 ms.
4. **Hit events.** `event_id` values are unique; `at_ms` lies within the attack duration; `critical: true` requires `damage > 0`.
5. **Channels.** `channel_id` values are unique; a channel starts within the attack and may extend at most 1000 ms beyond it (feedback tail). A channel `event_id`, when present, must reference a hit event.
6. **Damage numbers.** A `damage_number` channel must reference a hit event with `damage > 0`.
7. **Budgets.** Total hit-stop duration must not exceed `max_hit_stop_ms`; camera-shake intensity must not exceed `max_shake_amplitude`; channel count must not exceed `max_total_channels`.
8. **Concurrency.** At any channel start instant, active channels must not exceed `max_concurrent_channels`.
9. **Provenance.** `base_sha`/`head_sha` are lowercase 40-hex Git object IDs; evidence URI is required when `measurement_status` is `MEASURED`.
10. **Representation only.** Passing schema validation does not prove game feel, readability or performance.

## Validation

```powershell
python -m unittest discover -s tests/contracts -p 'test_*.py' -v
```

The tests use the repository's limited standard-library schema checker with local `$ref` expansion; unsupported keywords are avoided.

## Ownership

`ownership.v1.json` maps prospective M10 write paths (`nex_modules/animation/**`) to single writers. The paths do not exist yet and no module is admitted. Contract consumers are read-only.

## Compatibility

A breaking change to a required field, enum, availability semantics or provenance meaning requires `feedback.v2` and a new ownership revision. Additive optional fields are allowed only after the Steward updates this document and the tests.
