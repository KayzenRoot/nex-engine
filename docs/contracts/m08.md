# NEX M08 2.5D composition contract v1

**Status:** `CONTRACT_ONLY_NOT_MODULE_ADMISSION`. This document and the files under `contracts/m08/` define an interface and a prospective ownership map. They do **not** implement M08, create a layer or viewport, render 2.5D, measure performance, or admit any M08 sub-increment.

## Purpose

`composition.v1.schema.json` formalizes the DepthWeave draft: it describes one bounded 2.5D composition observation — reference to the M02 depth plan, ordered layer stack, depth policy, alpha policy, HUD/overlay safety, gameplay-critical entities, availability-gated performance and provenance.

## Invariants

1. **No fabricated measurements.** `MEASURED` requires a finite nonnegative value; `UNAVAILABLE` requires a reason and forbids a value.
2. **No FPS claim.** The contract carries frame intervals and millisecond timings, not FPS.
3. **Layer identity.** `layer_id` values are unique; `critical_entities[].entity_id` values are unique.
4. **HUD reference.** `overlay_safety.hud_layer_id` must reference a layer whose `role` is `hud`; HUD layers never declare `depth_override_m` and never enter the 3D depth passes.
5. **Depth policy.** `inherit_3d` forbids any layer-level `depth_override_m`; 2.5D layers may not silently reorder 3D gameplay primitives.
6. **Critical visibility.** If any critical entity has `must_remain_visible: true`, `alpha_policy.critical_guard` must be true; the contract never hides a gameplay-critical entity without an explicit guard.
7. **Overlay safety.** If `overlay_safety.may_cover_gameplay` is true and critical entities exist, `conflict_policy` must be `report`; conflicts are never silent.
8. **Base plan reference.** `plan_schema: none` requires every plan count/risk to be zero; a real `depth_composition.plan.v1` requires `plan_sha256` (lowercase 64-hex).
9. **Provenance.** `base_sha`/`head_sha` are lowercase 40-hex Git object IDs; evidence URI is required when `measurement_status` is `MEASURED`.
10. **Representation only.** Passing schema validation does not prove visual composition, HUD safety or performance.

## Validation

```powershell
python -m unittest discover -s tests/contracts -p 'test_*.py' -v
```

The tests use the repository's limited standard-library schema checker with local `$ref` expansion; unsupported keywords are avoided.

## Ownership

`ownership.v1.json` maps prospective M08 write paths (`nex_modules/render2_5d/**`) to single writers. The paths do not exist yet and no module is admitted. Contract consumers are read-only.

## Compatibility

A breaking change to a required field, enum, availability semantics or provenance meaning requires `composition.v2` and a new ownership revision. Additive optional fields are allowed only after the Steward updates this document and the tests.
