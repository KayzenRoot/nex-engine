# NEX M04 material contract v1

**Status:** `CONTRACT_ONLY_NOT_MODULE_ADMISSION`. This document and the files under `contracts/m04/` define an interface and a prospective ownership map. They do **not** implement M04, create a material, compile a shader, load a texture, measure performance, or admit any M04 sub-increment.

## Purpose

`material.v1.schema.json` describes one bounded PBR material observation: material identities, surface parameters, alpha/cull state, quality variants, texture references with digests and dimensions, a texture budget, explicitly available/unavailable performance metrics, and provenance binding the observation to a Git SHA, Godot version and hardware.

## Invariants

1. **No fabricated measurements.** `MEASURED` requires a finite nonnegative value; `UNAVAILABLE` requires a reason and forbids a value. Zero is a real measurement, never a substitute for missing data.
2. **No FPS claim.** The contract carries frame intervals and render timings, not FPS.
3. **Material and slot identity.** `material_id` values are unique in an observation; a material may reference at most one texture per `slot`.
4. **Alpha coherence.** `alpha_mode: mask` requires `alpha_cutoff`; `opaque` forbids it. A consumer must reject a contradictory pair.
5. **Texture budget.** Total textures must not exceed `max_texture_count`; the estimated decoded bytes (`width * height * 4`, multiplied by `4/3` when mipmaps are enabled) must not exceed `max_texture_bytes`. Digests are lowercase 64-hex SHA-256.
6. **Provenance.** `base_sha`/`head_sha` are lowercase 40-hex Git object IDs; `godot_version`, GPU model and driver are recorded. Evidence URI is required when `measurement_status` is `MEASURED`.
7. **Representation only.** Passing schema validation does not prove shader correctness, visual fidelity or performance; it proves the document is well-formed.

## Validation

```powershell
python -m unittest discover -s tests/contracts -p 'test_*.py' -v
```

The tests use the repository's limited standard-library schema checker with local `$ref` expansion; unsupported keywords are avoided.

## Ownership

`ownership.v1.json` maps prospective M04 write paths to single writers. Paths under `nex_modules/materials/**` do not exist yet and no module is admitted. Contract consumers are read-only; shared files (`nex_bench/project.godot`, `nex_bench/hub.gd`, contracts) require the Steward.

## Compatibility

A breaking change to a required field, enum, availability semantics or provenance meaning requires `material.v2` and a new ownership revision. Additive optional fields are allowed only after the Steward updates this document and the tests.
