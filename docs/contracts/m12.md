# NEX M12 visual identity contract v1

**Status:** `CONTRACT_ONLY_NOT_MODULE_ADMISSION`. This document and the files under `contracts/m12/` define an interface and a prospective ownership map. They do **not** implement M12, generate a logo or theme, approve a brand, measure on-screen contrast, or admit any M12 sub-increment.

## Purpose

`identity.v1.schema.json` describes one bounded visual-identity observation: palette tokens with roles, typography, SVG logo variants with digests/viewBox, spacing scale, accessibility/contrast requirements and provenance.

## Invariants

1. **Palette identity.** `token` values are unique; `primary`, `background` and `foreground` roles are required; `hex` is lowercase `#rrggbb`.
2. **Contrast.** `foreground`/`background` must meet `min_text_contrast_ratio`; `primary`/`background` and `error`/`background` must meet `min_large_text_contrast_ratio`; `success` and `warning`, when present, also meet the large-text threshold.
3. **Typography.** `display_size_px > body_size_px`; `weights` are unique multiples of 100; `line_height_ratio` is within 1.0–2.5.
4. **Logo.** Mark and wordmark are SVG URIs with lowercase 64-hex digests and positive `viewBox` width/height; a monochrome digest is required; `clear_space_ratio` is 0–1.
5. **Spacing.** `scale` is strictly ascending, every value is at least `base_px`, and `max_content_width_px` is at least 320.
6. **Accessibility.** `min_large_text_contrast_ratio` must not exceed `min_text_contrast_ratio`; when `requires_focus_indicator` is true, `min_focus_ring_px` is at least 1 (schema) and reported.
7. **No FPS.** This contract carries no frame metrics; an `fps` field is rejected.
8. **Provenance.** `base_sha`/`head_sha` are lowercase 40-hex Git object IDs; evidence URI is required when `measurement_status` is `MEASURED`.
9. **Representation only.** Passing schema validation does not prove brand approval, visual quality or measured on-screen contrast.

## Validation

```powershell
python -m unittest discover -s tests/contracts -p 'test_*.py' -v
```

The tests use the repository's limited standard-library schema checker; contrast is computed from the declared hex values with the WCAG relative-luminance formula.

## Ownership

`ownership.v1.json` maps prospective M12 write paths (`nex_modules/brand/**`) to single writers. The paths do not exist yet and no module is admitted. Contract consumers are read-only.

## Compatibility

A breaking change to a required field, enum, contrast semantics or provenance meaning requires `identity.v2` and a new ownership revision. Additive optional fields are allowed only after the Steward updates this document and the tests.
