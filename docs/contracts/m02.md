# NEX M02 render core contract v1

**Status:** `CONTRACT_ONLY_NOT_MODULE_ADMISSION`. This document and the schemas under `contracts/m02/` define an interface and a prospective ownership map. They do **not** implement M02, create a scene, measure performance, or admit any M02 sub-increment.

## Purpose

`render_core.v1.schema.json` describes one bounded render observation for the future isometric 3D module: camera intent, frozen render settings, explicitly available/unavailable performance metrics, and provenance binding the observation to a Git SHA, Godot version and hardware. It exists so that M02 sub-increments can consume/produce a stable interface before any renderer work is admitted.

## Invariants

1. **No fabricated measurements.** `MEASURED` requires a finite nonnegative value; `UNAVAILABLE` requires a reason and forbids a value. Zero is a real measurement, never a substitute for missing data.
2. **No FPS claim.** The contract carries frame intervals and render timings, not FPS. A consumer must not derive an FPS claim from synthetic/headless data.
3. **Camera completeness.** `isometric_orthographic` requires `ortho_size_m`; `isometric_perspective` requires `vertical_fov_degrees`. A consumer must reject `far_clip_m <= near_clip_m`.
4. **Provenance.** `base_sha` and `head_sha` are lowercase 40-hex Git object IDs; `godot_version`, GPU model and driver are recorded. Evidence URI is optional but required when `measurement_status` is `MEASURED`.
5. **Frozen settings.** Renderer is `godot.forward_plus`; driver is `vulkan` or `d3d12`; vsync, MSAA, shadow quality and cascades are enumerated. A consumer comparing two observations must reject differing settings instead of mixing them.
6. **Representation only.** Passing schema validation does not prove GPU behavior, correctness, or performance; it proves the document is well-formed.

## Ownership

`ownership.v1.json` maps prospective M02 write paths to single writers and declares contract consumers. The map is prospective: paths under `nex_modules/render3d/**` do not exist yet, and no module is admitted. Before any future implementation, the Integration Steward must rebind the paths to the actual Git tree and revalidate disjointness. Contract consumers are read-only; shared files (`nex_bench/project.godot`, `nex_bench/hub.gd`, `contracts/m01/**`) require the Steward and are never written by a sub-increment.

## Validation

```powershell
python -m unittest discover -s tests/contracts -p 'test_*.py' -v
```

The tests use the repository's limited standard-library schema checker. It is not a complete Draft 2020-12 validator; schemas avoid `$ref` and unsupported keywords so the checks remain meaningful in this environment.

## Compatibility

A breaking change to a required field, enum, availability semantics or provenance meaning requires a new contract version (`render_core.v2`) and a new ownership revision. Additive optional fields are allowed only after the Steward updates this document and the tests.
