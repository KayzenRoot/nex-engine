# NEX M07 advanced 2D pipeline contract v1

**Status:** `CONTRACT_ONLY_NOT_MODULE_ADMISSION`. Defines an interface and prospective ownership only. It does not implement M07, create a canvas, measure performance, or admit any M07 sub-increment beyond the wave's contract scope.

## Purpose

`render2d.v1.schema.json` describes one bounded 2D canvas observation for the future advanced 2D pipeline: canvas layers/transforms, material and lighting intent, particle emitters, batching counters, explicit availability semantics for performance metrics, and provenance binding to Git SHAs, Godot version and hardware. It lets future M07 increments consume a stable interface without coupling to the 3D renderer.

## Invariants

1. **No fabricated measurements.** `MEASURED` requires a finite nonnegative value; `UNAVAILABLE` requires a reason and forbids a value. Zero is a real measurement.
2. **No FPS claim.** The contract carries frame intervals and render timings only. Synthetic or headless data must not be promoted to an FPS claim.
3. **Identity and references.** Layer and material IDs are unique; every layer references a declared material; z-indices are unique. A consumer must reject duplicate or dangling references instead of silently merging them.
4. **Batching coherence.** `batch_groups <= max_draw_calls`.
5. **Particles.** An `emitting` emitter must declare `amount >= 1`; a zero-amount emitter must be non-emitting.
6. **Provenance.** Lowercase 40-hex Git SHAs; Godot version, GPU model and driver recorded; evidence URI required when provenance is `MEASURED`.
7. **Renderer.** Godot `forward_plus` with Vulkan or D3D12; VSync and max FPS enumerated. Consumers comparing observations must reject differing settings.

## Ownership

`ownership.v1.json` is a prospective map: `nex_modules/render2d/**` paths do not exist yet and no module is admitted. Before implementation, the Integration Steward rebinds paths to the real Git tree and revalidates disjointness. `nex_bench/project.godot`, `nex_bench/hub.gd` and `contracts/m01/**` are shared read-only inputs controlled by the Steward.

## Validation

```powershell
python -m unittest discover -s tests/contracts -p 'test_*.py' -v
```

The repository's limited standard-library schema checker is intentionally not a complete Draft 2020-12 validator; this schema avoids `$ref` and unsupported keywords so the checks remain meaningful.

## Compatibility

Breaking required fields, enums, availability semantics or provenance meaning requires `render2d.v2` and a new ownership revision. Additive optional fields require a Steward update to this document and the tests.
