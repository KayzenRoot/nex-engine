# NEX M09 preset pack contract v1

**Status:** `CONTRACT_ONLY_NOT_MODULE_ADMISSION`. This document and the files under `contracts/m09/` define an interface and a prospective ownership map. They do **not** implement M09, apply a preset, change `project.godot`, measure performance, or admit any M09 sub-increment.

## Purpose

`preset_pack.v1.schema.json` describes one bounded editor/quality preset pack: named presets across low→ultra/custom tiers, optional settings blocks for rendering, lighting, performance, 2.5D composition, feedback and accessibility, contract/hardware compatibility and provenance.

## Invariants

1. **Preset identity.** `preset_id` values are unique; standard tiers (`low`, `medium`, `high`, `ultra`) appear at most once; `custom` may repeat.
2. **Settings content.** Every preset has at least one settings block; blocks use the enums and ranges of the corresponding module contracts.
3. **Tier monotonicity.** Across consecutive standard tiers, `resolution_scale`, `shadow_quality` rank, `shadow_atlas_size` and `target_fps` must not decrease when present.
4. **Reduced motion.** When `feedback.reduced_motion` is true, `shake_scale <= 0.5` and `hit_stop_scale <= 1.0`.
5. **Compatibility.** `contract_versions` values are unique; the pack names a Godot version range and a hardware tier.
6. **No FPS measurement.** `target_fps` is a preset target, not a measured claim; a top-level `fps` field is rejected.
7. **Provenance.** `base_sha`/`head_sha` are lowercase 40-hex Git object IDs; evidence URI is required when `measurement_status` is `MEASURED`.
8. **Representation only.** Passing schema validation does not prove that a preset is applicable, visually acceptable or performant.

## Validation

```powershell
python -m unittest discover -s tests/contracts -p 'test_*.py' -v
```

The tests use the repository's limited standard-library schema checker; tier monotonicity and reduced-motion rules are checked by an independent consumer.

## Ownership

`ownership.v1.json` maps prospective M09 write paths (`nex_modules/tools/**`) to single writers. The paths do not exist yet and no module is admitted. Contract consumers are read-only.

## Compatibility

A breaking change to a required field, enum, tier semantics or provenance meaning requires `preset_pack.v2` and a new ownership revision. Additive optional fields are allowed only after the Steward updates this document and the tests.
