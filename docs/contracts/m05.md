# NEX M05 SpellFX contract v1

**Status:** `CONTRACT_ONLY_NOT_MODULE_ADMISSION`. This document and the files under `contracts/m05/` define an interface and a prospective ownership map. They do **not** implement M05, create a particle system, emitter, light or decal, measure performance, or admit any M05 sub-increment.

## Purpose

`spellfx.v1.schema.json` describes one bounded spell-VFX observation: spells, elemental identity, phase timelines, emitter descriptors, gameplay authority, decal policy, an FX budget, explicitly available/unavailable performance metrics, and provenance.

## Invariants

1. **No fabricated measurements.** `MEASURED` requires a finite nonnegative value; `UNAVAILABLE` requires a reason and forbids a value.
2. **No FPS claim.** The contract carries frame intervals and render timings, not FPS.
3. **Identity.** `spell_id` values are unique; phase names are unique per spell; `emitter_id` values are unique per spell.
4. **Impact required.** Every spell declares an `impact` phase; no spell is accepted without one.
5. **Gameplay authority.** `damage_owner` and `hit_detection` must be `gameplay`; a visual-only spell cannot own damage or hit detection. VFX never overrides gameplay authority.
6. **Light bridge coherence.** An emitter with `kind: light` must set `light_bridge: true`; any other kind must set it false.
7. **Budget.** Total emitters, particles, GPU emitters and decals must each fit their `fx_budget` maximum. Total phase duration must not exceed 60000 ms.
8. **Provenance.** `base_sha`/`head_sha` are lowercase 40-hex Git object IDs; evidence URI is required when `measurement_status` is `MEASURED`.
9. **Representation only.** Passing schema validation does not prove visual quality, combat clarity or performance.

## Validation

```powershell
python -m unittest discover -s tests/contracts -p 'test_*.py' -v
```

The tests use the repository's limited standard-library schema checker with local `$ref` expansion; unsupported keywords are avoided.

## Ownership

`ownership.v1.json` maps prospective M05 write paths to single writers. Paths under `nex_modules/vfx/**` do not exist yet and no module is admitted. Contract consumers are read-only; shared files require the Steward.

## Compatibility

A breaking change to a required field, enum, availability semantics or provenance meaning requires `spellfx.v2` and a new ownership revision. Additive optional fields are allowed only after the Steward updates this document and the tests.
