# NEX Engine · Brand guidelines

**Status:** `BRAND_SYSTEM_READY_FOR_UI / DISTRIBUTION_TRADEMARK_PENDING` · Issue #17
**Scope:** identity, mark construction, outlined wordmark, palette, icon rules, raster app icons and identity contract. This is the brand system reference; it does not modify the editor UI, `project.godot`, launchers or installer.

## 1. Concept

The mark is an **isometric "N"** inside a hexagonal frame: three strokes (two verticals and a diagonal) suggest a 3D grid seen from the ARPG camera, while the hexagon reads as a bounded engine core. A small amber diamond marks the baseline (measurement) without resembling any third-party logo.

The identity is original work for NexLabs. It is **not derived from the Godot logo**, and the Godot trademark policy is respected: the engine's own branding is independent, and Godot credit remains legal text, not brand borrowing.

## 3. Palette

| Token | Hex | Role |
|---|---|---|
| Graphite | `#0b0f14` | Background |
| Cobalt | `#2f6bff` | Primary |
| Cyan | `#35d0ff` | Accent |
| Amber | `#ffb020` | Warning / measurement |
| Mist | `#e8eef7` | Foreground |

Contrast: Mist on Graphite is **16.48:1**; Cobalt on Graphite is **4.27:1** (large text/shapes); Cyan is **10.63:1**; Amber is **10.51:1**. Body copy uses Mist. Amber is reserved for measurement/benchmark semantics, never for errors.

## 4. Clear space and minimum size

- Clear space: 25% of the mark height on all sides.
- Minimum digital sizes: mark 16 px (favicon), 24 px (icon), 48 px (launcher); primary logo 160 px wide.
- Never rotate, skew, outline, recolor outside the palette, or place the mark on busy photography.

## 5. Typography

The wordmark is built from **outlined geometric paths** in `wordmark.svg` and `logo-primary.svg`; it has no `<text>` element and no font dependency. The UI font is independent of the wordmark and may use the host system stack. No font binaries are shipped by this brand kit.

## 6. Icon rules

- 24×24 viewBox, 1.8 px stroke, round caps/joins, no fills except where geometry requires.
- `currentColor` only; icons inherit the text color.
- No text, shadows, gradients or external references inside icons.
- Icons are UI affordances, not decoration; keep one metaphor per icon.

## 7. App icons

The nine PNG sizes (16/24/32/48/64/128/256/512/1024) are rendered from `logo-mark.svg` by `nex_modules/brand/tokens/render_brand_assets.gd`. ICO and ICNS containers are generated by `docs/benchmarks/m12/tools/build_brand_kit.py`. The 16 px icon remains legible as a hexagonal mark with the cyan diagonal.

## 8. Integration (future, not admitted)

The brand assets are **not integrated into the editor UI, launcher, installer or engine binaries**. S02–S06 remain future Work Orders under #17. Any integration that touches `nex_bench/project.godot`, editor icons or installers requires its own admission, file inventory and Steward lock.
